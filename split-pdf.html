Split PDF

Keep only the pages you need, or break a PDF into single pages.

How to use Split PDF

  1. Tap Choose a PDF file and pick your document.
  2. Choose Keep some pages, or choose Every page separately.
  3. For Keep some pages, type the pages you want, for example 1-3, 5, 8-10.
  4. Tap Split PDF, then download your new file.

About this tool

Split PDF helps when you only need part of a big document. Send a single page of a form, extract one chapter from a book, or break a long scan into separate pages.

Choose Keep some pages and type the page numbers you want, such as 1-3, 5, 8-10. You get one new PDF with just those pages, in the same order. Choose Every page separately to get a zip file that holds one PDF for each page.

Your original file is never changed. The tool creates new files for you to download.

Your file stays on your device. It is processed inside your browser and is never uploaded to a server.

Questions

How do I write the page numbers?

Use commas to separate pages and a dash for a range. For example, 1-3, 5, 8-10 keeps pages 1, 2, 3, 5, 8, 9 and 10. Writing 8- keeps page 8 to the last page.

What is inside the zip file?

When you choose Every page separately, the zip has one PDF per page. The files are numbered in order, so they are easy to sort.

Will the original PDF be changed?

No. You always get new files and your original stays as it was.

Can I split a password-protected PDF?

Not yet. Remove the password first, then try again.
