Compress PDF

Make a PDF smaller so it is easy to email or upload.

How to use Compress PDF

  1. Tap Choose a PDF file and pick your document.
  2. Choose how small you want it: Good quality, Balanced or Smallest file.
  3. Tap Compress PDF and wait while each page is processed.
  4. Check the new size, then tap Download.

About this tool

Compress PDF makes a large PDF smaller so that it is easy to email or upload to a website with a size limit, such as a job portal or an exam form.

The tool turns every page into an optimised picture and builds a new PDF from those pictures. This can shrink scanned notes, photos and forms a lot. The trade-off is that text in the new file can no longer be selected or searched, so this tool is best for scans and documents you only need to view or print.

Balanced is the right choice for most files. Choose Good quality when the pages have small print, and Smallest file when you are fighting a strict upload limit.

If the new file would be bigger than your original, the tool tells you and does not offer it for download. PDFs that are mostly text are often already small. Your file stays on your device. It is processed inside your browser and is never uploaded to a server.

Questions

How much smaller will my PDF get?

It depends on the file. Scans and photo-heavy PDFs can shrink a lot. PDFs that are mostly text may not shrink at all.

Why can I not select text after compressing?

Compression converts pages into pictures. That is what makes the file small, but it also removes the selectable text.

Which option should I choose?

Start with Balanced. If the file is still too big, try Smallest file. If the print is hard to read, try Good quality.

Is my PDF uploaded?

No. Compression happens in your browser.
