PDF to Text

Pull out the text from a PDF and save it as a .txt file.

How to use PDF to Text

  1. Tap Choose a PDF file and pick your document.
  2. Tap Extract text.
  3. Wait while every page is read.
  4. Tap Download to save the .txt file, then open it to copy or translate the text.

About this tool

PDF to Text pulls the words out of a PDF and saves them in a plain text file. You can then copy them into another app, search through them or translate them.

It works for PDFs where the words are real text, such as ebooks, exported documents and online forms. Scanned PDFs are only pictures of pages, so there is no text to read. This tool does not include text recognition for scans, and it tells you clearly when it finds no text.

Only the text is saved. Images, tables and page layout are not kept.

Your file stays on your device. It is processed inside your browser and is never uploaded to a server.

Questions

Why does it say no text was found?

The PDF is probably a scan, where each page is a picture. Such files have no text inside them for the tool to read.

Does it keep the formatting?

No. You get plain text. Fonts, colours, images and layout are left out.

Does it work with Hindi text?

If the PDF stores Hindi as text, it is extracted. Some PDFs use special fonts and may give unusual characters.

Is my PDF uploaded?

No. The text is read in your browser.
